  void setInfo([string info]);
  info: 追加情報(省略した場合""になる)
説明
  パケット名にカーソルを合わせた時に出す追加情報を指定する。

  uint8 readChar([string name, bool isShow]);
  name: 値の名称(省略した場合"Unknown"になる)
  isShow: リストに表示するか否か(省略した場合trueになる)
説明
  1byte読んでその値を符号付き8bit整数として返す。

  name: 値の名称(省略した場合"Unknown"になる)
  isShow: リストに表示するか否か(省略した場合trueになる)
説明

書式
  string readIPPort([string name, bool isShow]);
  name: 値の名称(省略した場合"Unknown"になる)
  isShow: リストに表示するか否か(省略した場合trueになる)
説明
  IPアドレス(4bytes)、Port(4bytes)を読みそれを文字列にしたものを返す。
  値の名称はname + "IP:Port"として表示される。
